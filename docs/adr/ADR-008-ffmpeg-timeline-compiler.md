# ADR-008：FFmpeg 时间线编译器

> 状态：已验证（竖屏混音字幕母版）；烧录字幕受本机构建限制  
> 日期：2026-07-25  
> 关联计划：M0-08；M3-07；M4 粗剪/成片  
> 证据：[M0-08 spike](../spikes/M0-08-ffmpeg-master.md)

## 背景

成片与预览都依赖 FFmpeg。若允许 UI 透传任意滤镜字符串：

- 注入与难测组合爆炸  
- 预览与成片结果不一致  
- 字幕/混音规格漂移  

需要固定编译模型与安全边界。

## 决策

1. **时间线非破坏**：只存素材引用与参数；不覆盖源文件  
2. **编译器模式**：时间线修订 → 校验资产 → 解析平台覆盖 → 编译受控执行计划 → 渲染/混音/字幕 → mux → 校验 → 登记 Deliverable  
3. **预览与成片同源编译器**：  
   - 预览可用代理素材与更快 preset  
   - **最终成片重新读取源素材**，不从预览代理导出当母版  
4. **禁止** UI/插件直接提交原始 filtergraph 字符串；只允许预定义模板 + 结构化参数  
5. **输出**仅任务暂存 → 校验 → 项目 `renders/`  
6. **字幕策略（V1 默认）**：  
   - 内部结构化字幕段  
   - 成片优先 **软字幕**（ASS 源 → `mov_text` / 容器支持的字幕轨）  
   - **硬烧录**仅在 FFmpeg 构建含 libass 且探测 ready 时启用  
7. **规格基线**：竖屏 1080×1920；单集样片/门禁片 &lt; 90s 可验收；产品单集 90～120s  
8. **探测脚本**：`scripts/m0_08_ffmpeg_master.py`

### 本机探测结论（2026-07-22）

| 项 | 状态 |
|----|------|
| FFmpeg 8.0.1 Homebrew | 可用 |
| 竖屏 Ken Burns + 人声/配乐混音 | ready |
| 软字幕 ASS→mov_text | ready |
| ass/subtitles/drawtext 烧录 | unavailable（无 libass/freetype） |

## 替代方案

### 每次手写 ffmpeg 命令模板散落各处

短期快，长期必分裂。不采用；统一编译器模块。

### 预览直接当母版

快，质量与合法性差。禁止。

### 强制硬烧录字幕

部分平台需要，但本机默认构建可能不支持；作可选能力而非唯一路径。

## 影响

- M4 时间线 UI 只编辑结构化模型  
- 生成清单保存 FFmpeg/FFprobe 版本与脱敏命令预览  
- Grok 视频 unavailable 时用同一编译器做关键帧运镜降级  
- 发布流水线可选择绑定带 libass 的 FFmpeg 组件（ADR-007）  

## 回退

1. 无 libass → 软字幕 + 播放器叠加（当前默认）  
2. 编码失败 → `libx264`+`aac` 优先，VideoToolbox 可选  
3. 复杂滤镜需求 → 扩展模板库，不开放任意字符串  

## 后续验证

- 预览与成片同一时间线修订的像素/音画对齐抽检  
- 90～120s 多轨混音性能  
- 带 libass 构建的硬烧录开关探测
